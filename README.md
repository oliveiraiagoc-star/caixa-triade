# Caixa da Tríade

Livro-caixa da Tríade MIL: entradas e saídas por conta, importação de extrato (OFX/CSV) e fechamento mensal com a divisão do lucro entre os sócios.

- **Site:** GitHub Pages (`index.html`).
- **Dados:** planilha Google "Caixa da Tríade", acessada por um Apps Script publicado como app da Web (`apps-script/Code.gs`).
- **Acesso:** o site pede a senha do caixa. A senha fica só no Apps Script, nunca neste repositório.
